# Hikari Linux audio configuration

PipeWire DSP profiles and WirePlumber configuration for Apple Silicon Macs.
The retained snapshot includes speaker profiles for J274, J293, J313, J314,
J316, J375, J413, and J415, with additional model aliases generated by `make`.
Microphone profiles are included for the supported laptops. This rebrand does
not add or validate hardware support, including M6.

## Dependencies

- speakersafetyd
- linux-asahi 6.12.12-1 or above (7.1.6-1 for M3)
- PipeWire 1.0 or above
- WirePlumber 0.5.2 or above
- Bankstown 1.1.0 or above
- Triforce 0.2.0 or above
- LSP Plugins 1.0.20 or above (LV2 plugins)
- ALSA UCM profiles from `alsa-ucm-conf-hikari` or the compatible upstream package

These are the snapshot's dependency requirements. Speaker safety depends on
compatible kernel drivers, UCM profiles, and speakersafetyd; do not bypass them.

## Installation

On Linux with GNU make and coreutils:

```sh
make
make install PREFIX=/usr DESTDIR="$pkgdir"
```

Packaging installs profiles under `/usr/share/hikari-audio` and `99-hikari.conf`
for PipeWire and WirePlumber. Replace/conflict with `asahi-audio`; installing
both sets of configuration would load duplicate filters. External plugin URIs,
hardware matches, and speakersafetyd interfaces retain their existing names.
Upstream Packit jobs have been removed; no upstream packaging is fetched at build time.
